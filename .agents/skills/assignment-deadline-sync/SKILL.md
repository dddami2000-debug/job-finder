# 과제 마감 캘린더 동기화

학교 사이트에서 과목명, 과제명, 마감일을 확인하고 날짜가 명확한 과제만 Google Calendar에 동기화한다.

## 학교 사이트 확인

- 사용자가 로그인해 둔 브라우저 세션으로 제공된 학교 홈페이지나 LMS 링크를 연다.
- 과제 목록과 접근 가능한 과제 상세 페이지를 확인한다.
- 로그인, 2단계 인증 또는 보안문자가 필요하면 사용자가 브라우저에서 직접 완료하도록 요청한다. 인증 정보를 채팅으로 요청하지 않는다.
- 사이트가 접근을 차단하거나 필요한 페이지를 볼 수 없으면 우회하지 않고 확인하지 못한 범위를 알린다.

## 과제 정보 추출

각 과제에서 다음 정보를 찾는다.

- 과목명
- 과제명
- 마감일 또는 마감 일시
- 출처 URL

페이지에 명시된 날짜만 사용하고 날짜를 추측하지 않는다. 여러 과제는 마감일이 가까운 순서로 정리한다.

## 캘린더 동기화

- 마감일이 명확한 과제는 해당 마감일의 종일 일정으로 등록한다.
- 일정 제목은 `[과목명] 과제명` 형식을 사용한다.
- 가능하면 일정 설명에 과제 출처 URL을 기록한다.
- 생성 전 출처 URL로 기존 일정을 먼저 찾는다. URL이 없으면 과목명, 과제명, 마감일을 함께 비교한다.
- 같은 과제의 일정이 있으면 중복 생성하지 않는다.
- 기존 과제의 과목명, 과제명 또는 마감일이 바뀌었으면 기존 일정을 수정한다.
- Google Calendar 연결을 사용할 수 없으면 일정 작업을 중단하고 추출한 과제 목록과 필요한 연결 조치를 알려준다.
- 생성이나 수정이 실패하면 자동 재시도를 반복하지 않고 실패 항목과 원인을 보고한다.

## 애매한 정보 처리

- 마감일이 없거나 명확하지 않은 과제는 캘린더에 등록하지 않는다.
- 해당 과제는 `날짜 없는 할 일`로 분류하고 과목명, 과제명, 출처 URL을 보여준다.
- 일정 제목이나 중복 판정에 영향을 주는 정보가 애매할 때만 사용자에게 확인한다.
- 명확하게 확인된 과제는 사용자가 동기화를 요청한 범위 안에서 별도의 재확인 없이 처리한다.

## 완료 보고

다음 항목을 구분해 마감일이 가까운 순서로 보고한다.

- 새로 등록한 일정
- 업데이트한 일정
- 변경 없이 유지한 일정
- 날짜 없는 할 일
- 실패했거나 확인하지 못한 항목
